# By Linh

Persönliche Geschenke und individuelle Gestaltungen. Statische Website auf GitHub Pages unter https://www.bylinh.de.

## Struktur

- HTML-Seiten im Hauptordner
- assets/css/: Gestaltung und mobile Anpassungen
- assets/js/: Projektgalerie und Animationen
- assets/images/: Bilder und responsive Größen
- projekte/: bestehende Projektadressen; zwei zurückgezogene Beispiele führen zu neutralen Hinweisseiten
- CNAME: bestehende Domainkonfiguration

Etsy dient als Bestellweg für vorhandene Angebote. Individuelle Anfragen laufen über das eingebettete Tally-Formular. Ein Push auf main veröffentlicht über GitHub Pages.
