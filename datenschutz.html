Zweck der Verarbeitung

Deine Angaben werden zur individuellen Bearbeitung deiner Anfrage, zur Kontaktaufnahme und ggf. zur Auftragsabwicklung gespeichert und verwendet.

Welche Daten werden verarbeitet?

  • Name
  • E-Mail-Adresse
  • Angaben zum Wunschprodukt und Anlass
  • Weitere von dir freiwillig gemachte Angaben

Zusätzlich können personenbezogene Daten über Kommunikationskanäle wie WhatsApp, Instagram oder das Tally-Formular übermittelt werden. Diese Daten werden ausschließlich zur Beantwortung deiner Anfrage oder zur Auftragsabwicklung verwendet. Ich empfehle, keine sensiblen Daten über soziale Medien zu senden.

Wie lange werden die Daten gespeichert?

Deine Daten werden nur so lange gespeichert, wie sie für die Bearbeitung deiner Anfrage oder Auftragsabwicklung notwendig sind. Gesetzliche Aufbewahrungsfristen bleiben unberührt.

Weitergabe an Dritte

Deine Daten werden nicht an Dritte weitergegeben und ausschließlich zur Bearbeitung deines Anliegens verwendet.
